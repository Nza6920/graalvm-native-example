RuntimeHints 速查表

当 JVM 正常、Native 异常时，用故障行为选择最小提示类型。

动态行为入口典型症状
按名称加载和调用类hints.reflection()ClassNotFoundException、找不到构造器或方法
读取 classpath 文件hints.resources()getResourceAsStream() 返回 null
创建 JDK 动态代理hints.proxies()代理接口组合未注册
JNI 访问hints.jni()Native 方法或字段不可访问

精确反射注册

hints.reflection().registerType(MyPlugin.class, type -> type
    .withConstructor(List.of(), ExecutableMode.INVOKE)
    .withMethod("run", List.of(), ExecutableMode.INVOKE));

导入 registrar

@ImportRuntimeHints(MyRuntimeHints.class)

精确资源注册

hints.resources().registerPattern(
    "greetings/resource-greeting.txt");

资源路径从 classpath 根开始，不加 classpath: 前缀。只有确实需要整个目录时才使用类似 greetings/** 的宽泛模式。

精确 JDK 代理注册

hints.proxies().registerJdkProxy(
    MyFirstInterface.class,
    MySecondInterface.class);

接口顺序属于代理组合的一部分：[A, B] 和 [B, A] 是两个不同注册。如果是 Spring AOP 代理，还要考虑 Spring 自己附加的代理接口。

判断流程

普通 JVM 测试
   ↓ 通过
原生测试
   ↓ 失败
按异常定位动态行为
   ↓
添加最小 hint
   ↓
重新构建并运行原生测试
提示不是越多越好。优先精确注册实际调用的类型、构造器、方法、资源模式或接口组合。
